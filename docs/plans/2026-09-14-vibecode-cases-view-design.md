# Дизайн страницы Вайбкодинг-компонентов (вид кейса)

**Дата:** 14 сентября 2026  
**Ветка:** `main`  
**Автор:** Ernest von Schuldiais & Antigravity  

---

## 1. Контекст и цели

Текущая страница `/cases` отображала список вайбкод-кейсов в виде сетки двухколоночных карточек (`CaseCard` с обложками). 

**Цель:** Переработать страницу `/cases` (открывающуюся по клику на «Vibecode кейсы» с главной) в **«вид кейса»** согласно предоставленному дизайну:
- Страница повторяет структуру и размерности стандартного кейса: верхний отступ `pt-[300px]`, максимальная ширина `max-w-[956px]`, логотип сверху слева, заголовок и описание.
- Логотип — иконка `</>` (`/images/icons/code.svg`).
- Заголовок отображает название со счётчиком опубликованных компонентов в скобках: например, `Вайбкодинг компоненты (2)`.
- Описание задаёт контекст: `Здесь я собираю разные интересные способы завайбкодить простые элементы интересным способом`.
- Компоненты располагаются друг за другом в порядке, заданном в админке (`VibecodeOrderManager`).
- Каждый компонент представлен интерактивной превью-областью (iframe с живым компонентом) и верхней строкой: название слева, ссылка «На весь экран» справа.

## 2. Структура и модель данных

1. **Тексты и конфигурация шапки:**
   - Хранятся в `messages/ru.json` и `messages/en.json` в секции `vibecodePage`:
     ```json
     "vibecodePage": {
       "title": "Вайбкодинг компоненты",
       "description": "Здесь я собираю разные интересные способы завайбкодить простые элементы интересным способом",
       "fullScreen": "На весь экран"
     }
     ```
     Для английской версии:
     ```json
     "vibecodePage": {
       "title": "Vibecoding components",
       "description": "Here I collect interesting ways to vibecode simple elements in a fun and interactive way",
       "fullScreen": "Full screen"
     }
     ```
2. **Список компонентов:**
   - Загружаются серверным методом `getVibecodeCases()` из `lib/cases.ts` (`c.published && c.category === "vibecode"`), уже отсортированные по `vibecodeOrder`.
   - Не требуется добавление специальных фиктивных кейсов в `cases.json` — соблюдается принцип KISS & YAGNI.

## 3. Вёрстка и компоненты

### 3.1. Шапка кейса (идентична GalleryCaseView)
- Контейнер: `max-w-[956px] box-content mx-auto px-6 pt-[300px]`
- Логотип: `/images/icons/code.svg` (размер `w-[120px] h-[120px] object-contain`, отступ снизу `mb-[36px]`).
- Заголовок `h1`: `text-[42px] md:text-[50px] font-bold leading-[46px] md:leading-[54px] tracking-tight text-foreground` с динамическим счётчиком `({count})`.
- Описание: `mt-[24px] mb-[12px]` с компонентом `RichText` (типографика и цвета как у любого кейса).

### 3.2. Карточка превью компонента (`VibecodeItemPreview`)
Структура по аналогии с компонентом «Превью» (`CasePreview`), но вместо картинки — интерактивная область:
- **Отступ между компонентами:** `56px` (`mb-[56px]`).
- **Верхняя строка:** `flex justify-between items-baseline mb-[32px]`
  - Слева: `h2` — название компонента (`text-[28px] font-medium leading-[36px] text-[#9C9C9C]`).
  - Справа: ссылка `Link` «На весь экран» (`text-[28px] font-medium leading-[36px] text-[#9C9C9C] hover:text-white transition-colors cursor-pointer select-none`) на `/${locale}/cases/${case.slug}`.
- **Интерактивная область (визуал `CaseCard` с главной без нижней текстовой части и без реакций наведения):**
  - Внешний контейнер: `w-full rounded-[28px] p-3 bg-[#1F1C18] relative overflow-hidden` (статичный, без 3D-наклона и spotlight-градиента).
  - Внутренний контейнер: `w-full h-[600px] rounded-2xl bg-[#16130F] overflow-hidden relative`.
  - Внутренняя тень: оверлей с `pointer-events-none rounded-2xl z-10` и стилем `boxShadow: "inset 0 0 50px rgba(255,255,255,0.03)"`.
  - Внутри: `iframe` (`src={case.componentUrl}`, `w-full h-full border-0 relative z-0`), интерактивный — можно кликать и взаимодействовать.
  - Адаптивность: высота `h-[420px] md:h-[600px]`.

### 3.3. Навигация и переключатель языка
- Сверху фиксированная `CaseNavigation` с кнопкой «Назад» на главную.
- В правом нижнем углу `LanguageSwitcher` (как на всех страницах кейсов).
